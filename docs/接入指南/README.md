# 接入指南

本指南按“安装 → 初始化与隐私 → 广告形式 → 竞价 → 生命周期与排错”的顺序组织。[接入概览](../../README.md)提供快速开始；完整 API 语义以当前版本公开头和下列指南为准。

## 使用顺序

1. 先阅读安装方式，选择 CocoaPods 或手动集成中的一种。
2. 按隐私与网络要求完成宿主授权和请求前配置。
3. 选择实际使用的广告形式，按对应指南接入。
4. 需要竞价时再阅读竞价指南；遇到问题先看生命周期与排错说明。
