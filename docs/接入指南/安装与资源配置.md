# 安装与资源配置

[接入概览](../../README.md) · [运行示例](../../YSIFLYADLibSimple/README.md)

选择 CocoaPods、SwiftPM 或 TOS 手动集成中的一种，固定版本 `6.5.1`，避免重复链接 SDK 或重复拷贝资源。不要混用版本或重复加入资源。

## 环境要求

- 最低部署目标为 iOS 11.0。
- 交付为静态 XCFramework，包含设备与模拟器切片。最终 App 链接需要 `-ObjC`；手动集成使用 **Do Not Embed**。
## 选择安装方式

选择 CocoaPods、SwiftPM 或 TOS 手动集成中的一种，固定版本 `6.5.1`，避免重复链接 SDK 或重复拷贝资源。

### CocoaPods

```ruby
source 'https://cdn.cocoapods.org/'
platform :ios, '11.0'

target 'YourApp' do
  use_frameworks!
  pod 'YSIFLYADLib', '6.5.1'
end
```

```bash
pod install
open YourApp.xcworkspace
```

此版本使用上述 CocoaPods 官方 trunk 安装，依赖已发布到 CocoaPods trunk。CocoaPods 自动加入资源、`-ObjC` 和所需系统库；安装后始终打开 `.xcworkspace`。

## Swift Package Manager

在 Xcode 的 **File → Add Package Dependencies** 添加 `https://github.com/LJMcarryu/YSIFLYADLib_iOS.git`，选择 **Exact Version 6.5.1**，向 App target 添加 **YSIFLYADLib** Product。二进制由 TOS 下载，同版资源随资源 target 投递。

App target 的 **Other Linker Flags** 保留 `$(inherited) -ObjC`，链接 `AdSupport.framework`，将 `AppTrackingTransparency.framework` 设为 **Optional**。不要同时安装 CocoaPods 或手动 framework。

可直接运行本仓 [YSIFLYADLibSwiftPMSimple](../../YSIFLYADLibSwiftPMSimple/README.md)，打开其 workspace 后由 Xcode 解析远程包。

## 手动集成

从 [6.5.1 发布记录](https://download-adsdk.voiceads.cn/ios_sdk/6.5.1/ys/fast-release-record.json) 下载完整包 [`YSIFLYADLib-6.5.1.zip`](https://download-adsdk.voiceads.cn/ios_sdk/6.5.1/ys/YSIFLYADLib-6.5.1.zip)，其中包含 framework 与资源。解压后：

1. 将 `YSIFLYADLib.xcframework` 加入 App target，选择 **Do Not Embed**。
2. 将 `YSAdvSDK.bundle` 加入 **Copy Bundle Resources**，确认最终 App 只有一份。
3. 在 App target 的 **Other Linker Flags** 添加 `$(inherited) -ObjC`。
4. 链接 `AdSupport.framework`，将 `AppTrackingTransparency.framework` 设为 **Optional**，兼容 iOS 11～13。

三种方式统一导入：

```objc
#import <YSIFLYADLib/YSIFLYADLib.h>
```

本版完整包：[下载 YSIFLYADLib-6.5.1.zip](https://download-adsdk.voiceads.cn/ios_sdk/6.5.1/ys/YSIFLYADLib-6.5.1.zip)。
