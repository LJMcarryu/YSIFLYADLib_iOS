# 安装与资源配置

[返回首页](../../README.md) · [运行示例](../../YSIFLYADLibSimple/README.md)

同一 App 选择 CocoaPods 或 TOS 手动集成；若已有独立 SwiftPM 包源，再按包源说明接入。不要混用版本或重复加入资源。

## 环境要求

- 最低部署目标为 iOS 11.0；SwiftPM 清单要求 Swift tools 5.9。
- 交付为静态 XCFramework，包含设备与模拟器切片。最终 App 链接需要 `-ObjC`；手动集成使用 **Do Not Embed**。
- SwiftPM 接入使用支持 Swift tools 5.9 清单的 Xcode；反馈构建问题时请提供实际 Xcode 版本与完整错误。

## 选择安装方式

选择 CocoaPods 或 TOS 手动集成，生产项目固定到正式版本 `6.5.0`；已有独立 SwiftPM 包源时再按包源说明接入。

### CocoaPods

```ruby
source 'https://cdn.cocoapods.org/'
platform :ios, '11.0'

target 'YourApp' do
  use_frameworks!
  pod 'YSIFLYADLib', '6.5.0'
end
```

```bash
pod install
open YourApp.xcworkspace
```

此版本使用上述 CocoaPods 官方 trunk 安装，依赖已发布到 CocoaPods trunk。CocoaPods 自动加入资源、`-ObjC` 和所需系统库；安装后始终打开 `.xcworkspace`。

### Swift Package Manager（需要独立包源）

TOS 静态网站可以提供 SwiftPM 所需的二进制文件，但不能直接作为 Xcode 的 SwiftPM package URL。若项目已有公司内部 SwiftPM 包源，请按包源提供的 `Package.swift` 接入并固定版本 `6.5.0`；其中的 `binaryTarget` 应指向本页的 TOS 资产地址。

没有独立包源时，使用 CocoaPods 官方 trunk 或下面的 TOS 手动集成方式。SwiftPM 或手动集成时，在最终 App target 的 **Other Linker Flags** 中保留 `$(inherited)` 并添加：

```text
-ObjC
```

### 手动集成

从 [6.5.0 发布记录](https://download-adsdk.voiceads.cn/ios_sdk/6.5.0/ys/fast-release-record.json) 下载完整包 [`YSIFLYADLib-6.5.0.zip`](https://download-adsdk.voiceads.cn/ios_sdk/6.5.0/ys/YSIFLYADLib-6.5.0.zip)，其中包含 framework 与资源。解压后：

1. 将 `YSIFLYADLib.xcframework` 加入 App target，选择 **Do Not Embed**。
2. 将 `YSAdvSDK.bundle` 加入 **Copy Bundle Resources**，确认最终 App 只有一份。
3. 在 App target 的 **Other Linker Flags** 添加 `$(inherited) -ObjC`。
4. 链接 `AdSupport.framework`，将 `AppTrackingTransparency.framework` 设为 **Optional**，兼容 iOS 11～13。

CocoaPods 与 TOS 手动集成统一导入：

```objc
#import <YSIFLYADLib/YSIFLYADLib.h>
```

本版完整包：[下载 YSIFLYADLib-6.5.0.zip](https://download-adsdk.voiceads.cn/ios_sdk/6.5.0/ys/YSIFLYADLib-6.5.0.zip)。
